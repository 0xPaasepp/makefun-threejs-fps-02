A tactical 5v5 FPS across a desert saltworks at dusk. Buy your kit, take a lane, and plant the Charge. Built for [make.fun](https://make.fun/competition/threejs-fps-02).

Run `node serve.ts --port 8080`. WASD move, mouse aim/fire, R reload, C crouch, Space jump, E plant, B buy, 1–3 equip, G grenade.
